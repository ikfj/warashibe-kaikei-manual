1このシステムについて

父母の会の会計を、1つの Google スプレッドシート（以下「スプシ」）で管理する仕組みです。スプシに「父母の会会計」という専用メニューが付いていて、面倒な計算や転記はメニューから自動で行えます。

このシステムでできること：

  • 園児・家庭の名簿管理（入園・退園・駐車場利用の変更）
  • 父母の会費・駐車場利用料の請求金額の計算と、家庭別の請求リストの作成
  • ゆうちょダイレクトの入出金明細（CSV）の取り込みと、入金と家庭の自動照合（消込）
  • 未納家庭の一覧、年度末の収支決算（会計報告）の作成

このシステムで扱わないこと（システムの外で行います）：

  • 現金の取り扱い（すべて銀行口座経由で行う前提です）
  • 支払期限・督促の管理、予算管理、駐車場の区画数の管理
  • 銀行での振込操作（返金の振込など）
大切な考え方スプシは人が直接読み書きできる表になっています。メニューは手間を減らすための道具で、データの正本はスプシの表そのものです。メニューが使えないときも、表を手で編集すれば運用を続けられます（15章）。

2使い始める前に

スプシを受け取る

当年度のスプシ（名前は YYYY年度_父母の会会計）は、前任の会計担当者から Google ドライブの共有で受け取ります。パソコンのブラウザ（Chrome 推奨）で開いてください。スマートフォンのアプリでは専用メニューが表示されません。

専用メニューの場所

スプシを開いて数秒待つと、画面上部の「ヘルプ」の右に 父母の会会計 メニューが表示されます。表示されないときは、ページを再読み込みしてください。

父母の会会計
├─ 初期設定 ─── 初回セットアップ
├─ 年度初め ─── 新年度セットアップ / 新入園児一括登録 / 請求金額計算
├─ 日常業務 ─── 入園処理 / 退園処理 / 駐車場利用変更 /
│               CSV取込（入出金明細登録）/ 入金消込実行
└─ 出力更新 ─── 請求リスト更新 / 未納リスト更新 / 会計報告更新

この手順書では、メニューの操作を 日常業務 → 入園処理 のように書きます。

初めてメニューを使うときの承認

初めてメニューを実行すると「承認が必要です」という画面が出ます。次の手順で許可してください（アカウントごとに最初の1回だけです）。

  1. 「続行」を押し、自分の Google アカウントを選ぶ。
  2. 「このアプリは Google で確認されていません」と表示されたら、「詳細」→「（プロジェクト名）に移動」を押す。父母の会で独自に作ったスクリプトのため、この表示が出ます。
  3. 求められた権限（スプレッドシートの閲覧・編集、ドライブのファイル操作、メニュー・ダイアログの表示）を確認して「許可」を押す。
  4. もう一度、同じメニューを実行する。

個人情報の取り扱い

必ず守ってください
  • スプシには園児の氏名などの個人情報が入っています。共有は会計担当者と必要最小限の役員だけにしてください。
  • 「リンクを知っている全員」での共有は使わないでください。
  • 担当者が交代するときは、新しい担当者に権限（オーナー権限を含む）を渡し、旧担当者の権限を外します。前年度以前のアーカイブファイルも同じように権限を管理します。

5年度初め（4月）

始める前に新年度セットアップは、前年度の年度末の作業（9章）がすべて終わってから行います。未納が残っている（損金を計上していない）家庭があると、セットアップは中止されます。また、前年度繰越金は [出力]会計報告 の「次年度繰越」から転記されるので、最後の取込・消込の後に会計報告更新を実行してからセットアップしてください。
  1. 月額を決める
    父母の会費（園児1人あたりの月額）と駐車場利用料（1家庭あたりの月額）を決めておきます。
  2. 新年度セットアップを実行する
    年度初め → 新年度セットアップ を実行し、確認画面で「はい」を押します。次のことが自動で行われます。
    • 今のスプシのコピーが YYYY年度_父母の会会計_アーカイブ という名前で同じフォルダに作られる（閲覧専用）
    • 在園児が1つ上のクラスに進級する（さくらは卒園としてはずれる）
    • 家庭マスタの長子・識別子が更新される
    • 前年度の「次年度繰越」が設定シートの「前年度繰越金」に転記される
    • 年度が更新され、会費・駐車場料の月額が空欄になる（駐車場賃貸事業者名カナは前年度から引き継がれる）
    • 今のスプシのファイル名が新しい年度に変わる（例：2026年度_父母の会会計 → 2027年度_父母の会会計）。ファイル名に年度が入っていない場合は変わりません。
  3. 設定シートを入力・確認する
    「父母の会費（月額/園児）」と「駐車場利用料（月額/家庭）」を入力します。「前年度繰越金」が前年度の会計報告の「次年度繰越」と一致しているかも確認します。駐車場の貸主が変わった場合は「駐車場賃貸事業者名カナ」も直します（7章）。
  4. 新入園児を一括登録する
    新入園児の CSV を用意して（下の「新入園児CSVの作り方」）、年度初め → 新入園児一括登録 から CSV ファイルを選び「一括登録」を押します。最後に登録数とスキップ数が表示されます。
  5. 駐車場利用アンケートを反映する
    Google フォームなどで集めた駐車場利用の希望を、家庭マスタの「駐車場利用」列に ○ か × で入力します。前年度の値が残っているので、全家庭分を見直してください。新入園で増えた家庭は × になっています。
  6. 識別子の重複を確認する
    家庭マスタの備考に 【要確認】識別子が家庭 F-xx-xxx と重複 と出ている家庭があれば、その家庭の「識別子」を手で決めて入力します（13章）。
  7. 振込人名義を確認する
    新しい家庭の「振込人名義」は、最初の入金があったときに CSV の表記に合わせて入力します（6章）。
  8. 請求金額を計算する
    年度初め → 請求金額計算 を実行します。請求シートに、園児ごとの会費と、駐車場利用家庭ごとの駐車場料の行が作られます。
  9. 請求リストを出力する
    出力更新 → 請求リスト更新 を実行し、[出力]請求リストを印刷・配布します（5月請求）。

1行目に見出し、2行目以降に1人1行で書きます。列の順番は変えないでください。

クラスひよこ／つくし／たんぽぽ／すみれ／ゆり／さくら のどれか。「さくら組」のように「組」を付けるとエラーになり、その行は登録されません。

6入金の取込と消込

銀行口座の入出金をスプシに取り込み、入金を「どの家庭の何の支払いか」に結びつける作業（消込）です。月1回程度、入金が増える5〜6月はこまめに行うと楽です。

CSVを取り込む

  1. ゆうちょダイレクトからCSVをダウンロードする
    ゆうちょダイレクトにログインし、入出金明細の照会画面で期間を指定して CSV をダウンロードします。一度に全期間は取れないので、前回取り込んだ日以降を指定します。期間が前回と重なっても、同じ取引は二重に登録されません。
  2. 取り込む
    日常業務 → CSV取込（入出金明細登録） を実行し、ダウンロードした CSV を選んで「取込実行」を押します。CSV はそのまま（Shift-JIS のまま）選んでください。
  3. 結果を確認する
    「取込完了: X件（入金Y件・出金Z件）、未照合W件」と表示されます。残高のつながりがおかしいという警告が出た場合は、取り込んでいない期間がないか確認し、抜けている期間の CSV を取り込んでください。

取り込むと、次のように自動で処理されます。

  • すべての取引が「入出金明細」に追加される（銀行の利息は「受取利子」の1行だけが入り、その内訳の「利子」「税金」の行は取り込まれない）
  • 銀行の利息（「受取利子」の行）は、入金消込に消込種別＝受取利子・照合方法＝自動で追加される（手作業は不要）
  • 入金は「入金消込」に追加される。振込人名義が家庭マスタと一致し（スペースの有無は区別しない）、かつ金額がその家庭の未納額とぴったり一致したものだけ、自動で家庭に結びつけられる（照合方法＝自動）
  • それ以外の入金は「照合方法＝未照合」として残る（次の手順で手作業）
  • 出金は「出金分類」に追加される（7章）

未照合の入金を処理する

  1. 「入金消込」シートを開き、照合方法が「未照合」の行を探します（フィルタを使うと便利です）。
  2. 入出金明細ID から「入出金明細」シートの同じ ID の行を見て、摘要2（振込人名義）と金額を確認し、どの家庭からの入金か特定します。名義は一致したが金額が違う場合は、備考に候補の家庭IDが書かれています。
  3. 「家庭ID」列に家庭IDを入力します。
  4. 「消込種別」を確認します（会費／駐車場利用料 など。付録参照）。
  5. 「照合方法」を 手動 に変更します。これで処理完了です。
会費と駐車場料をまとめて振り込まれた場合1件の入金を2行に分けます。同じ入出金明細IDで行をもう1行追加し、1行目を「会費」、2行目を「駐車場利用料」にして、それぞれの金額を入れます。2行の消込金額の合計が入金額と一致しているか確認してください。新しい行の消込IDは、一番下の行の続き番号にします。
分割払い・不足分の追加払い入金ごとに消込行を作ればよく、特別な操作は要りません。未納リストは「請求の合計 − 消込済みの合計」で計算されるので、何回に分けて払われても正しく反映されます。
会費・駐車場料以外の入金家庭IDは空欄のまま、消込種別を設定して照合方法を「手動」にします。寄付や雑収入は「その他収入」です。銀行の利息は自動で「受取利子」になるので、手作業は不要です。

振込人名義を登録・修正する

家庭マスタの「振込人名義」は、CSV の摘要2と一致したときだけ自動照合に使われます。スペースの有無や全角・半角スペースの違いは区別しません（例：ﾕﾘ ﾔﾏﾀﾞ ﾀﾛｳ と ﾕﾘﾔﾏﾀﾞﾀﾛｳ は同じ名義とみなします）。新しい家庭の最初の入金を手で消込したら、その摘要2をコピーして家庭マスタの「振込人名義」に貼り付けておくと、次回から自動で照合されます。

  • 他の銀行からの振込は通常カタカナ（例：ヤマダ　タロウ）、ゆうちょ銀行からの振込は漢字の「姓　名」になります。カタカナ・漢字の別や文字は CSV のとおりに入力してください。
  • 祖父母名義での振込など、名義が家庭マスタと違う入金は毎回手作業になります。
  • 同じ名義（スペースを除くと同じになる名義を含む）が複数の家庭に登録されていると、その名義は自動照合されません（誤りを防ぐため）。

「入金消込実行」メニューについて

日常業務 → 入金消込実行 は、未照合のまま残っている入金について、名義と金額による自動照合をもう一度試します。振込人名義を後から登録・修正したときに使ってください。

7出金の分類

CSV を取り込むと、出金は「出金分類」シートに追加されます。

  • 摘要2が設定シートの「駐車場賃貸事業者名カナ」と完全に一致する出金は、自動で「駐車場賃料」になります。
  • それ以外はいったん「その他支出」になるので、内容を見て正しい出金種別（事務費・慶弔費・図書費・手数料・返金・その他支出）に直し、「支払先・返金先」も入力してください。
  • 返金の場合は「家庭ID」を入力し、備考に退園返金か誤入金返金かを書きます。

8請求リスト・未納リスト

[出力] シートは自動では更新されません。元のシートを変更したら、必要なリストをメニューから更新してください。

メニュー出力される内容使うタイミング
出力更新 → 請求リスト更新家庭ごとの識別子、在園児数、駐車場利用、会費合計、駐車場料、請求合計、請求日5月の一斉請求、途中入園・駐車場利用開始の後
出力更新 → 未納リスト更新未納額が残っている家庭の、請求合計・入金済み合計・未納額消込の後、督促の前
出力更新 → 会計報告更新収支決算、出金一覧、入金一覧、口座残高との照合結果年度末（期中に途中経過を見てもよい）
識別子とは家庭を見分けるための名前で、ふつうは「長子のクラス_姓（漢字）長子の名（かな）」（例：たんぽぽ_山田そら）です。姓がない家庭は「長子のクラス_長子の名（かな）」（例：つくし_エマ）になります。長子は家庭内でいちばん上のクラスにいる園児です。請求リストなどの配布物に印刷されます。

9年度末（3月）

  1. 最後の取込と消込
    3月末までの CSV を取り込み、未照合の入金をすべて処理します（6章）。出金分類も確認します。
  2. 督促
    未納リストを更新し、未払いの家庭に連絡します（システムの外での作業）。
  3. 未納を損金として計上する
    年度末まで払われなかった未納額は、必ず損金として計上します（翌年度に繰り越して請求はしません）。「入金消込」シートの一番下に、家庭ごとに1行追加します。

    消込ID一番下の行の続き番号（例：M-26-0123 の次は M-26-0124）
    入出金明細ID空欄（銀行の取引がないため）

    消込金額未納額
    消込種別損金

  4. 会計報告を作成する
    出力更新 → 会計報告更新 を実行します。完了メッセージの「口座残高照合」が 一致 になっていることを確認してください。「不一致（差額 ±N円）」の場合は、CSV の取り込み漏れ、未処理の入金、前年度繰越金の誤りがないか調べます。
  5. 会計監査
    監査役に [出力]会計報告 の入金一覧・出金一覧と通帳を突き合わせてもらいます。
  6. 会計報告書の作成
    出力をもとに総会用の会計報告書を作ります。「次年度繰越」の金額を控えておきます。

ここまで終わったら、新年度のセットアップ（5章）に進めます。

会計報告は期中にも実行できます途中経過の確認に使えます。ただし期中は消込前の入金が収入に入らないため、残高照合が「不一致」になることがありますが、異常ではありません。

10途中入園

  1. 日常業務 → 入園処理 を実行し、姓・名・姓かな・名かな・クラス・入園年月（例：2026-07）を入力します。外国人名で姓がない場合は、姓・姓かなを空欄にします。きょうだいが在園している場合は「きょうだい在園」欄にその子の園児IDを入力します（いなければ空欄）。「登録」を押します。
  2. 入園の翌月に 年度初め → 請求金額計算 を実行します。その園児の会費の請求行が追加されます（すでにある請求行はそのままで、二重に請求されることはありません）。
  3. 出力更新 → 請求リスト更新 を実行し、その家庭に請求します。
途中入園の会費入園した月から3月までの月数分です（日割りはしません）。例：7月入園なら 7月〜3月の9か月分を、8月に請求します。

11途中退園と返金

  1. 日常業務 → 退園処理 を実行し、園児IDと退園年月（例：2026-09）を入力して「退園処理」を押します。
    • その園児の会費の請求が、在園した月数（入園月〜退園月、どちらも含む）に減額されます。
    • 家庭に在園児がいなくなり、駐車場の請求がある場合は、駐車場の請求も減額されます。
    • 画面に返金予定額（支払済みの会費 − 在園月数分の会費）が表示されるので、控えておきます。
  2. 返金予定額を銀行からその家庭に振り込みます（システムの外での作業）。
  3. 振込後、ゆうちょダイレクトの CSV を取り込みます（6章）。
  4. 「出金分類」シートでその出金の出金種別を 返金 に直し、家庭IDを入力し、備考に「退園返金」と書きます。

12駐車場利用の変更

  1. 日常業務 → 駐車場利用変更 を実行し、家庭ID、変更区分（開始／停止）、適用年月（例：2026-08）を入力して「変更を反映」を押します。
  2. 開始の場合：年度初め → 請求金額計算 を実行します。適用年月から3月までの駐車場料の請求行が追加されます。
    停止の場合：その家庭の駐車場料の請求が、利用開始から停止した月までの月数に自動で減額されます。払いすぎの金額が表示されたら、退園の返金と同じ手順（11章の2〜4）で返金します。
  3. 請求リスト・未納リストを更新します。

開始の月・停止の月はどちらも1か月分として計算します（日割りはしません）。

13特別なケース

識別子が他の家庭と重複した

姓・長子の名かな・長子のクラスが同じ家庭が2つあると、識別子が同じになり配布物で取り違えるおそれがあります。この場合は識別子が自動で作られず、家庭マスタの備考に 【要確認】識別子が家庭 F-xx-xxx と重複 と書かれます。

その家庭の「識別子」列に、保護者が見分けられる名前を手で入力してください（例：たんぽぽ_山田そら（はな姉））。手で入力した識別子は、進級や長子の変更があっても上書きされません。

双子が入園した・双子の片方が退園した

入園：1人目を登録して園児IDを確認し、2人目の登録時に「きょうだい在園」欄（一括登録なら「きょうだい園児ID」列）に1人目の園児IDを入れます。先に登録した1人目が長子になります。

片方の退園：長子だった方が退園すると、もう1人が自動で長子になり、識別子の名前の部分が更新されます。

一時退園した園児が復園した（育休など）

新しく入園処理はしません。園児マスタでその園児の「退園年月」を消して空欄にします（園児IDはそのまま）。休んでいた期間の会費は、請求シートのその園児の行の「対象月数」と「請求金額」を手で直し、備考に YYYY-MM復園・調整 と書きます。手で直した請求行は、請求金額計算を実行しても上書きされません。

入園を取りやめた（登録したが通園しなかった）

行は削除せず、退園処理で「退園年月」を入園年月と同じ月にします。すでに請求行がある場合は、対象月数と請求金額を 0 にし、備考に 入園辞退・無請求 と書きます。

会費の減免・割引をしたい

専用の機能はありません。請求シートのその行の「対象月数」または「請求金額」を手で直し、備考に理由を書いてください。

間違って振り込まれた（誤入金）
  1. 入金消込シートのその入金の行の消込種別を 誤入金 にし、照合方法を「手動」にします。
  2. 振込手数料を差し引いた金額を返金します。
  3. 返金の出金を CSV で取り込んだら、出金分類で出金種別を 返金 にし、備考に「誤入金返金」と振込手数料の金額を書きます。
前年度の未納分が新年度に振り込まれた

前年度に損金として計上した未納分が新年度に払われたときは、新年度の入金消込で消込種別を その他収入 にします。家庭IDは入れてかまいません。備考に「前年度未納分」と書いてください。前年度のアーカイブは修正しません。

CSVにない取引を登録したい

入出金明細シートの一番下に手で行を追加します（明細IDは続き番号、登録方法は「手入力」、CSV明細番号は空欄）。そのうえで入金なら入金消込、出金なら出金分類に、その明細IDの行を手で追加します。

14初めて導入するとき

前年度のスプシがない最初の年だけの手順です。2年目以降は5章の手順を使います。

  1. システムが入った空のスプシを開くと「このスプレッドシートは未初期化です」と表示されます。初期設定 → 初回セットアップ を実行します（すでにデータがある場合は中止されます）。
  2. 設定シートに、年度、父母の会費・駐車場料の月額、駐車場賃貸事業者名カナ、前年度繰越金（発足時に持っているお金。なければ 0）を入力します。
  3. 全在園児（ひよこ〜さくらの全員）を CSV にして、年度初め → 新入園児一括登録 で登録します（CSVの作り方）。初年度だけは新入園児ではなく全員が対象です。
  4. 以降は5章の手順5（駐車場アンケートの反映）から続けます。

15困ったとき

「父母の会会計」メニューが表示されない

パソコンのブラウザで開いているか確認し、ページを再読み込みしてください。スマートフォンのアプリには表示されません。

入力画面のボタンを押すと「PERMISSION_DENIED」のエラーが出る

「ストレージからの読み取り中にサーバーエラーが発生しました。エラーコード: PERMISSION_DENIED」と表示される場合は、ブラウザで複数の Google アカウントにログインしていることが原因です。入力画面のあるメニュー（新入園児一括登録・入園処理・退園処理・駐車場利用変更・CSV取込）で起こります。エラーの時点ではデータは変更されていません。

次のどれかの方法で、スプシを使うアカウントだけでログインした状態にしてから、もう一度実行してください。

  • シークレットウィンドウを開き、スプシを使うアカウントだけでログインしてスプシを開く（いちばん手軽）
  • Chrome で、スプシを使うアカウント専用のプロファイルを作り、そこでスプシを開く（毎回の手間がなくなります）
  • いったんすべての Google アカウントからログアウトし、スプシを使うアカウントで最初にログインし直す
エラーのメッセージが出た

メッセージに書かれている原因（入力の形式、存在しないIDなど）を直して、もう一度実行してください。エラーで止まった場合、データは変更されていません。原因がわからないときは、メッセージの画面を撮って開発担当に相談してください。

間違えて編集・実行してしまった

スプシの ファイル → 変更履歴 → 変更履歴を表示 から、操作する前の版に戻せます。期中の自動バックアップはないので、大きな操作の前にはこの方法で戻せることを覚えておいてください。

同じCSVを2回取り込んでしまった

問題ありません。同じ取引（CSV明細番号が同じ）は自動でスキップされ、二重には登録されません。

請求金額計算を何回も実行してしまった

問題ありません。すでにある請求行はスキップされ、まだ請求行がない園児・家庭の分だけが追加されます。

会計報告の残高照合が「不一致」になる

次の順で確認してください。

  1. 年度の全期間の CSV を取り込んだか（取込時の残高つながりの警告も確認）
  2. 入金消込に「未照合」の行が残っていないか
  3. 設定シートの前年度繰越金が、前年度の会計報告の次年度繰越と一致しているか
  4. CSV にない取引（現金のやりとりなど）がないか

メニューが使えないときの手作業での運用

スクリプトが動かなくなっても、スプシの表を直接編集して運用を続けられます。

  • 新しい行の ID は、そのシートの一番下の ID の続き番号にする
  • 入出金明細に取引を手で入力したら、入金消込または出金分類にも手で行を追加する
  • [出力] シートの保護を外し（データ → シートと範囲を保護）、SUMIF などの関数で集計して記入する
